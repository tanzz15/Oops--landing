## About the Project

**Oops!** is a 2D platformer game developed with a classic pixel-art visual style. Players explore floating islands, overcome obstacles, avoid enemies, and collect coins and fruits to unlock the next world.

The game focuses on platforming challenges, timing, exploration, and player precision.

## Features

- **Pixel-Art Graphics:** Classic retro-inspired 16-bit visual style.
- **Challenging Levels:** Platforms, obstacles, traps, and enemies.
- **Checkpoint System:** Three checkpoints available in Level 1.
- **Collectible Items:** Collect coins and fruits throughout the level.
- **Achievement System:** Six challenges to complete.
- **Free to Play:** Available for Windows.

## Gameplay

The main objective is to complete each level by:

1. Jumping between platforms.
2. Avoiding traps and patrolling enemies.
3. Collecting coins and fruits.
4. Reaching the final gate to unlock the next world.
